# BEC Attendance & Student Management System

Comprehensive attendance management, student roster portal, and reporting system for Bhubaneswar Engineering College (BEC).

## Key Features
- **3-Role Portal System:** Student, Teacher/Faculty, and Administrator dashboards.
- **Universal Student Database:** Integrated student roster across CSE, Data Science, ECE, EEE, Mechanical, Civil, Agriculture, and Aeronautical departments.
- **Flexible DOB Authentication:** Secure student login supporting DOB passwords with or without hyphen/slash symbols.
- **QR Code & Manual Attendance:** Classroom QR scanner with AI auto-zoom & instant session tracking.
- **Report Exporters:** Export class registers and section attendance summaries to PDF and Excel.
